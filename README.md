# 30 Days of AWS

Welcome to my 30-day journey of exploring Amazon Web Services (AWS) to master cloud fundamentals, services, and architecture.
Over the next month, I will dive deep into compute, storage, networking, security, and modern cloud-native solutions.
Every day, I will document my hands-on practice, core concepts learned, commands run, and real-world architectures built.
This repository serves as a personal log to track my progress, review key comparisons, and note common mistakes along the way.
Let's build in the cloud, learn from failure, and design secure, scalable, and highly available systems on AWS!
